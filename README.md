# La Maison Paris

L’hebdomadaire du mercredi et le cahier portefeuille du lundi, en app iPhone lisible hors connexion.
Site statique publié avec GitHub Pages. Pour l’installer : ouvrir l’adresse du site dans Safari, puis Partager, puis « Sur l’écran d’accueil ».

Informations générales, pas un conseil en investissement personnalisé.
